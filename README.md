# SCT_WD_4 – To-Do Web Application

A responsive **To-Do Web Application** built using **HTML, CSS, and JavaScript**. The application allows users to create, edit, complete, delete, organize, and filter tasks with a modern dark-themed interface.

## Live Demo

🔗 https://rajankumar2511.github.io/SCT_WD_4/

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* Assign date and time to tasks
* Add custom and predefined tags
* Filter tasks by tag
* Drag-and-drop task reordering
* Responsive design for desktop and mobile devices
* Modern dark UI with smooth interactions

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
* Flatpickr (Date & Time Picker)
* SortableJS (Drag-and-Drop Sorting)
* Font Awesome (Icons)

## How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
